# 打砖块 · 原理说明

挡板接住球，球撞到砖块就扣血；砖全部打完即过关。撞墙和砖块会略微加速，挡板接到球后速度回到初速。

## 一、文件与操作

| 文件 | 作用 |
| --- | --- |
| `index.html` | 关卡、分数、生命、画布、提示层 |
| `style.css` | 白底布局，画布自适应宽度 |
| `game.js` | 物理、碰撞、关卡、绘制循环 |

双击 `index.html` 即可，不需要服务器。

- 鼠标移动 / 手指拖：挡板跟着走
- `←` `→` 或 `A` `D`：键盘移动挡板
- 点击画布或空格：发球；游戏中再按空格暂停
- `R` 或「重开」：重开本关
- 过关后点「下一关」或再点画布进入下一关

逻辑分辨率固定 **480×640**。页面上画布会按宽度缩放，坐标换算用 `clientX` 映射回逻辑坐标，所以鼠标位置和挡板是对齐的。

## 二、核心原理

### 1. 对象

- **挡板**：矩形 `(x, PADDLE_Y, w, h)`。越往后关越短，最少 64 像素。
- **球**：圆心 + 半径。`stuck` 为 true 时吸在挡板上，等发球。
- **砖**：矩形 + `hp`。每撞一次减 1，到 0 就消失。图案里的 `S` 是 4 血，颜色最深。

发球时给一个稍微偏左或偏右的初速度，避免球永远竖直来回。各关初速都是 6.8。撞墙或砖块时速度再乘 1.045，上限 13；挡板接到球后，速度立刻回到 6.8，只保留新的反弹角度。移动时按最多 6 像素拆成多步，避免加速后一帧穿过整块砖。

砖的大小不变，都是浅蓝玻璃。剩余血量用深浅区分：1 血最浅，2 血、3 血依次加深，4 血最深。打掉一层，颜色马上变浅，直到消失。

撞到砖块时合成一声短促的玻璃叮声：高频正弦波加上一个很快消失的泛音。打碎时音调再高一点。第一次点击或按键之后才会出声，这是浏览器的限制。

### 2. 主循环

`requestAnimationFrame` 每帧：

1. 用两帧间隔算出 `dt`（相对 60fps 的倍数），上限 2，避免卡顿时球瞬移穿墙
2. 移动挡板
3. 移动球并做碰撞
4. 清空画布重画

### 3. 墙和底边

- 左右、上边：碰到就把对应方向的速度取反，并把球位置钳回场内，防止卡住
- 底边：球心掉到画布下面，扣 1 条命，球回到挡板上；生命为 0 失败

### 4. 挡板反弹（手感关键）

球从上方碰到挡板时，**不简单翻 `vy`**，而是按击中位置改角度：

```
t = (球心x - 挡板左) / 挡板宽     // 0 左 ~ 1 右
angle = (t - 0.5) * 0.72π         // 中间往上，两边往斜
vx = speed * sin(angle)
vy = -|speed * cos(angle)|        // 一定向上，避免卡在挡板里
```

打在中间，球几乎垂直上去，适合清中间的砖；打在边上，球更斜，适合清两侧。这是经典打砖块的手感来源。

### 5. 砖块碰撞

球是圆、砖是矩形。最近点法判断相交：

```
最近点 = 把圆心各轴钳到矩形范围内
若 圆心到最近点的距离 < 半径  → 撞上
```

撞上之后看**上一帧**球是在砖的左右外侧还是上下外侧：

- 从左右来 → 翻 `vx`
- 否则 → 翻 `vy`

然后普通砖 `hp -= 1`。打碎加分 `10 × 关卡`，只打到没碎加 2 分。一帧只处理一块砖，避免一次穿过两块时速度被翻两次又飞走。

过关条件：所有砖的 `hp` 都 ≤ 0。

### 6. 为什么用 Canvas 而不是 DOM

砖块、球每帧都在动，用一堆 `div` 改位置会又慢又抖。Canvas 一帧画完，适合这种连续物理。

## 三、关卡为什么这样排

砖块大小不变，按 9 列对齐摆放。每一关换的是哪些格子有砖，从而拼出不同轮廓。`#` 用这一关的血量，`S` 是 4 血（颜色最深，也能打掉），`.` 是空位。

| 关 | 形状 | 血量 |
| --- | --- | --- |
| 1 | 小金字塔 | 1 |
| 2 | 阶梯月牙，左右厚、中间薄 | 1 |
| 3 | 菱形 | 1 |
| 4 | 箭头 | 2 |
| 5 | 心形 | 2 |
| 6 | 方框，外圈 4 血 | 2 |
| 7 | 更大的阶梯月牙 | 2 |
| 8 | 几乎铺满，夹着 4 血的砖 | 3 |

难度来自：轮廓更弯、砖更多、血更厚、挡板更短。4 血的砖要多打几次，但一样能打掉。发球初速各关都是 6.8；只有在空中连撞时才会变快，接到球就回到初速。

生命固定 3 条。若要再加关，优先换图案和加血，初速不要再明显高于 9，上限保持在砖厚（22 像素）以内，配合分步移动才不容易穿模。
