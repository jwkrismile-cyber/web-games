# Web 游戏合集

纯 HTML / CSS / JavaScript 编写的网页小游戏，无需安装任何依赖，直接用浏览器打开即可。

在线游玩：https://jwkrismile-cyber.github.io/web-games/

| 游戏 | 目录 | 说明 |
| --- | --- | --- |
| 扫雷 | [`minesweeper/`](minesweeper/) | 每局随机布雷，首次点击必定安全，支持初级 / 中级 / 高级 / 自定义。原理见 [原理说明](minesweeper/原理说明.md) |
| 叠叠消 | [`triple-match/`](triple-match/) | 叠层三消，7 格卡槽，共 8 关。原理见 [原理说明](triple-match/原理说明.md) |
| 打砖块 | [`breakout/`](breakout/) | 挡板接球打砖，共 8 关。原理见 [原理说明](breakout/原理说明.md) |

## 本地运行

双击对应目录下的 `index.html` 即可。
